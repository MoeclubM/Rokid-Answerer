# 通用问答与代码分析 (general-qa)

## 解题策略
1. 文史/政治/法律/地理常识 → 优先 `web_search(query="...")` 联网搜索确认事实
2. 编程代码/Bug分析 → 直接推理，需要验证数值时用 `calculate`
3. 外语翻译 → 直接输出翻译，遇到专业术语联网确认 `web_search(query="...")`

## 知识库检索
通用问答一般不需要学科知识库，但如涉及理工交叉内容：
- `search_knowledge_base(query="相关主题关键词")`

## 联网搜索
通识类问题的核心手段：
- `web_search(query="具体问题描述")` 确保事实准确性
